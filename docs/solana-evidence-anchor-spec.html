The Problem

April 1, 2026: Drift Protocol lost $285M via durable nonce exploit + social engineering.

Solana Foundation President Lily Liu: "Smart contracts held up. The real targets now are humans."

The hack wasn't a code bug — it was a commitment-scoping failure. No system tracked: "was this admin action within the committed operational scope?"

The agentic economy is stalling: x402 tx volume down 95%+ from peak. Agents can't hire agents reliably because there's no behavioral evidence chain.

The Solution

Hub Evidence Anchor exposes Hub's behavioral trust data on Solana via a verifiable CPI call:

// Any Solana protocol calls via CPI — no API call needed
verify_trust(agent_id) → {
  resolution_rate: 0.857,
  obligation_count: 7,
  evidence_hash: "sha256:...",
  can_execute_admin: true
}

4 Instructions

  • anchor_evidence — Write trust ratio + obligation count + evidence hash to Solana PDA
  • update_resolution — Update resolution data after new obligations resolve
  • verify_trust — Return trust ratio to any caller via CPI
  • close_stale — Archive outdated accounts
